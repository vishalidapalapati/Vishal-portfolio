Propulsion Testing

Conducted static thrust testing across three propeller configurations to validate motor/propeller combinations for the UAV. Tests used the E-Flite Power 90 motor at four throttle settings (25%, 50%, 75%, 100%) for each propeller. The 16×8 3-Blade pusher propeller was selected as the optimal configuration.

Propeller Selection Rationale

  • Based on a 28 lb takeoff weight and 50% thrust-to-weight ratio, 14 lbs of thrust required — the 16×10 2-blade was immediately eliminated at 11 lbs max.
  • The 16×8 3-blade produces 15.6 lbs at full power; after ~10% pusher efficiency penalty still satisfies requirements.
  • Smaller diameter is critical in a pusher configuration to prevent prop strikes — aircraft must tailstrike before prop-strikes.
  • The 16×8 achieves near-equivalent thrust at 68A vs 73.8A for the 18×8, reducing thermal loading on the motor and ESC.

class CrewDisplay(QWidget):
    def __init__(self):
        super().__init__()
        self.theme = "light"
        self.state = "nominal"
        self.setWindowTitle("Shield-System Crew Display")
        self.resize(1024, 600)
        self.history = {k: deque(maxlen=300) for k in ["Power", "B", "Dose"]}

        self._apply_theme()
        self.set_state("nominal")

    def set_state(self, new_state):
        """Change system state: nominal / warning / critical"""
        self.state = new_state
        colors = COLORS[self.theme]
        self.emergency.hide()
        if new_state == "nominal":
            self.banner.hide()
            self.overlay.hide()
            if self.alarm: self.alarm.stop()
            accent = colors["good"]
        elif new_state == "warning":
            msg = random.choice(WARNINGS)
            self.banner.setText(f"  {msg}")
            self.banner.setStyleSheet(
                f"background:{colors['warn']}; font-weight:bold; font-size:20px;")
            self.banner.show()
            accent = colors["warn"]
        else:  # critical
            msg = random.choice(CRITICALS)
            self.banner.setText(f"  {msg}")
            self.banner.setStyleSheet(
                f"background:{colors['crit']}; font-weight:bold; font-size:22px;")
            self.banner.show()
            if "B-FIELD" in msg.upper():
                emergency_msg = "B-FIELD BELOW SAFE LIMIT\nSEEK SHELTER IMMEDIATELY"
            else:
                emergency_msg = "SYSTEM FAULT DETECTED\nEMERGENCY SHUTDOWN REQUIRED"
            self.emergency.setText(emergency_msg)
            self.emergency.resize(self.width(), self.height())
            self.emergency.show()
            self.emergency.raise_()
            if self.alarm: self.alarm.play()
            accent = colors["crit"]
        for label in self.status.labels.values():
            label.setStyleSheet(f"color:{accent}")
        self.current_accent = accent

    def _update_telemetry(self):
        """Generate and display simulated telemetry data"""
        power  = random.uniform(9, 10)
        bfield = random.uniform(0.13, 0.15)
        dose   = random.uniform(6, 9)
        self.status.update("Power",   f"{power:.2f} kW",    self.current_accent)
        self.status.update("B-Field", f"{bfield:.3f} T",   self.current_accent)
        self.status.update("Dose",    f"{dose:.1f} mSv/yr", self.current_accent)
        current_time = time.time()
        self.time_history.append(current_time)
        self.history["Power"].append(power)
        self.history["B"].append(bfield)
        self.history["Dose"].append(dose)
        for key, curve in self.curves.items():
            curve.setData(self.time_history, self.history[key])
        self._log_telemetry(power, bfield, dose)
        if int(current_time) % 30 == 0:
            self.state_index = (self.state_index + 1) % 3
            self.set_state(self.states[self.state_index])

    def keyPressEvent(self, event):
        if   event.text() == '1': self.set_state("nominal")
        elif event.text() == '2': self.set_state("warning")
        elif event.text() == '3': self.set_state("critical")

The differential corrector for the Phasing segment did not converge after 30 iterations. The satellite drifted to −115.34° instead of the target −90° West, with a residual drift rate of −2.76°/day. This was attributed to orbital perturbations during the 4-day propagation window. Future mitigation would involve more frequent phasing corrections or reducing the propagation window.

F-18 Flight Control System Design

Bank Angle Controller Design

Required integral action for zero steady-state error and aggressive phase lead to stabilize the 3 RHP poles. Initial design achieved very fast settling but required physically impossible aileron deflections (>800°). The revised controller balances performance with actuator constraints.

Initial PID Controller

C_φ(s) = 0.39854 · (s + 0.001882)(s + 2) / s

  • Settling time: 0.00343s — well within 3s requirement
  • Required aileron deflection: 800° — physically impossible
  • Stability: All closed-loop poles in LHP (via pole-zero cancellation of RHP pole at +1.4)

Revised Final Controller

C_φ(s) = 0.01417 · (s + 0.001882)(s + 3) / s

  • Settling time: ~3.03s — meets the <3s requirement
  • Aileron deflection: <45° — within physical limits
  • Bode plot: Phase margin = 88.3° at 11.2 rad/s — robust stability
  • Design insight: There is a fundamental trade-off between aggressiveness and physical realizability — the "perfect" controller does not exist; the goal is optimal performance within actuator constraints.

Velocity Controller Design

The velocity plant G_V(s) presented the most challenging design problem — severely unstable (3 RHP poles), very small DC gain (−0.0064), and 8th-order dynamics making analytical Routh-Hurwitz analysis impractical by hand.

Design Progression

  • Attempt 1 — Proportional controller: K_p = 2.7039×10⁵ appeared stable via root locus but poles remained in RHP — pole-zero cancellation illusion
  • Attempt 2 — IMC Auto-Tuning (sisotool): 14th-order controller — all poles in LHP but constant steady-state error, unpredictable behavior
  • Attempt 3 — MATLAB PIDTuner: Successfully stabilized the system
